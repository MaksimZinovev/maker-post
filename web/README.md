# Maker Post — Web Review App (web/)

Hosted web app for reviewing, tweaking, and approving AI-generated drafts before they post to Instagram.

- **Review screen** — single card: photo on top, caption below, Approve & Post + one-tap tweak row
- **Drafts list** — simple queue for bulk drafts (V5)
- **Setup/onboarding** — connect Instagram, seed style guide, install Shortcut
